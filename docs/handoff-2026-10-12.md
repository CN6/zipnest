## 发布配方（照这个顺序）

1. 6 处版本号同步：`apps/zipnest-native/src/main.rs` 的 `CURRENT_VERSION`、`packaging/installer.nsi`（`!define VERSION` + `OutFile`）、`packaging/win11-shell/AppxManifest.xml`、`README.md`（当前版本 + 两个产物名 + 大小）、`CHANGELOG.md` 新增段落 → 跑 `powershell -File packaging\check-versions.ps1`（必须 6 项全 ok）。
2. 门禁：`cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`。
3. `cargo build -p zipnest-native --release` 和 `cargo build -p zipnest-shell --release`。
4. `powershell -File packaging\emit-portable.ps1`（生成 `dist-portable\ZipNest`；跳过三方许可证的开关叫 `-NoThirdParty`，不是 `-ThirdParty`）。
5. 在 `packaging\` 下：`%LOCALAPPDATA%\tauri\NSIS\makensis.exe /V2 installer.nsi`（`installer.nsi` 的 UTF-8 BOM 不能丢）。
6. 便携包：`Compress-Archive dist-portable\ZipNest -DestinationPath ZipNest_<ver>_x64_portable.zip`。
7. 提交 → `git push origin master` → `git tag -f -a v<ver>` → `git push -f origin +refs/tags/v<ver>`。
8. `gh release create v<ver> <setup.exe> <portable.zip> --title "ZipNest v<ver>" --notes-file <UTF-8 无 BOM 的正文>`；用 `gh release view --json` 核对标题/产物大小/sha256 与本地一致。
9. 更新本机 `D:\ZipNest`（先关进程）→ 启动 → 删本地安装包/便携包/`dist-portable` → 可选 `cargo clean`。
10. 等 CI（3 个 job：版本号+安装包可编译 / 旧 Web UI 测试 / shipped crates test+clippy）绿。

## 硬性不变量（改代码前先读）

- **解压绝不丢文件**：`archive_security::plan_entry_paths` 在 `Extract` 之前把每个条目的名字映射成安全名（设备名加 `_`、非法字符换 `_`、`..`/盘符/UNC 前缀丢弃、超长截到 255 字节保留扩展名、冲突加 ` (n)`），永不失败；`ExtractStats::failed` 非空 ⇒ 这次解压必须报失败（`error.entries_failed`）并弹窗列文件名+原因，不能报"完成"。改名列表走 `extract_renamed` 事件。
- Windows 长路径：`extract.rs` 里所有 fs 调用都过 `os_path()`（超过 240 字符加 `\\?\` 前缀），临时文件名要保证 `名字 + .zipnest-part-…` ≤ 255。
- 写入用 `<名字>.zipnest-part-<pid>` 临时文件 + 原子改名，失败/取消不允许截断已有文件。
- 默认程序接管在 `crates/zipnest-ipc/src/user_choice.rs`（删掉重建 `FileExts\.<ext>\UserChoice` 并算 V1 哈希）；不要想着改 Windows 保护的标识符。
- `shell_register` 拒绝含 `/target/` 的 exe 路径（开发版不能注册关联，会提示 `error.shell.dev_path`）。

## 环境坑（踩过的）

- `edit`/`write` 工具会**去掉 UTF-8 BOM**；`packaging/installer.nsi`、`AppxManifest.xml`、`.ps1` 必须有 BOM（用 `[System.IO.File]::WriteAllText($p,$t,(New-Object System.Text.UTF8Encoding($true)))` 写并核对首字节 EF BB BF）。
- 绝不 `Get-Content`/`Set-Content` 读写仓库里的 UTF-8 中文文件（GBK 会乱码）；用 .NET + 显式 `UTF8Encoding`。
- PowerShell 5.1：**没有 heredoc**（提交信息/notes 先写字面文件再 `-F`）；**没有 `utf8NoBOM`**；`$Pid`/`$HOME` 是只读自动变量（参数别叫 `$Pid`）；`cargo` 的 stderr 在 `$ErrorActionPreference='Stop'` 下会被当成终止错误（用 `'Continue'`）。
- UI 自动化验证：UIA 找 `*ZipNest*` 顶层窗口，按按钮名 `InvokePattern`；**同名按钮取最后一个**（对话框在工具栏之后绘制）；截图要 `GetWindowRect` + 7/8 px 内缩（DWM 隐形边框）。验证"只有一个窗口"要枚举该进程全部顶层窗口。
- 长路径的目录用 `Remove-Item` 删不掉，用 `cmd /c rd /s /q "\\?\C:\..."`。
